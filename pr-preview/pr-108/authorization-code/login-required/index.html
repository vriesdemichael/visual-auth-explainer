Client type

Whether the client can keep a secret. One that cannot, such as a client in a browser, has to rely on PKCE.

The client proves it started this login, so a stolen code is no use alone. Current advice is to have it on, and a public client must.

Token type

Whether holding the token is enough, or the client must also prove it holds a key.
