In Keycloak: What its own API answers

This answer is from the demo API. Keycloak's own UserInfo answers the same way: a 401 with no error when there is no token, a 401 with invalid_token and Token verification failed when it does not accept one, and a 403 with insufficient_scope when the token does not have the openid scope.
