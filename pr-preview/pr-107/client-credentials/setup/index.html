Ask to register the app

The app team, which is probably you, asks an admin to register the app, and that it may act for itself. There is no address to list, because nobody gets sent back anywhere. People do this, so there is no message.

In practice. You do this once. An app acting for itself gets nobody’s permission but its own, so ask for only what it needs.
