What it carries

  • response_type=code query Asks for a code, which is what makes this the code flow.
  • client_id query Says which app this is, as registered in setup.
  • redirect_uri query Has to be the address the code was sent to.
  • state query A random value the app checks when the user comes back, so nobody can slip in an answer it did not ask for.
  • scope=openid query Asks for OpenID Connect on top of OAuth. From: OpenID Connect
  • nonce query A random value that comes back inside the ID token, so the app can tell the token is from this login. From: OpenID Connect
  • prompt=login query Says to ask for the password, even with a session. From: Log in to a second app, What happens at the second app
  • Cookie header Sent to this address, and to nowhere else From: Log in to a second app
