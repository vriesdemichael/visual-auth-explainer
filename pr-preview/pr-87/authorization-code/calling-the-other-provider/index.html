In Keycloak: Stored tokens readable

Gives each new user the role that lets their access token read the stored tokens. Without it, this request gets a 403. Users that already exist do not get it from this setting.

In Keycloak: A server option

API V1 is on unless the server is started with the V2 flag, and that turns it off, which the docs do not say. Set it where the server starts. It is not in the admin console.

--features=identity-brokering-api:v2

Tried with and without the flag on Keycloak 26.8.1.
